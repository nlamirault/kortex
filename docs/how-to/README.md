# How-to Guides

How-to guides are **task-oriented** — they show you how to accomplish specific goals in
Kortex. These guides assume you already know the basics.

## Available Guides

- [Ingest a New Source](example-task.md)

## What's a How-to Guide?

How-to guides solve a specific real-world problem. Unlike tutorials (which teach), how-to
guides assume you know what you want to do and just need the steps.
