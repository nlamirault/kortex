# Tutorials

Tutorials are **learning-oriented** — they teach you Kortex through guided, hands-on
practice. If you're new to Kortex, start here.

## Available Tutorials

- [Getting Started with Kortex](getting-started.md)

## What's a Tutorial?

Tutorials guide you through building something concrete, step by step. You learn by doing.
Unlike how-to guides (which solve a specific problem), tutorials are for beginners learning
the basics.
