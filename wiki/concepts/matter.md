# Overview

It is an **interoperability standard** backed by Apple, Google, Amazon, Samsung, and others.

👉 Matter allows devices to work **across ecosystems**, for example:

- add a device in Apple Home
- control it in Google Home
- and also in Alexa

… **without re-pairing it each time**.

![Thread-home-network.png](Reference%20Matter/Thread-home-network.png)

### 📡 What networks does Matter use?

Matter runs over:

- **Wi-Fi** (for powered devices such as plugs, cameras, appliances)
- **Thread** (for low-power sensors, switches, etc.)

👉 Zigbee is **not natively compatible**, but some hubs can act as **Zigbee → Matter bridges**.

### 👍 Pros

- true cross-platform compatibility
- modern, secure architecture (encryption, certificates)
- simplified setup via QR codes

### 👎 Current limitations

- the standard is still evolving
- some advanced features aren’t standardized yet
- older devices are being updated gradually
