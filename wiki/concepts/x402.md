# x402

x402 is a protocol that activates the long-dormant **HTTP 402 Payment Required** status
code to enable native, programmatic payments between machines — letting an AI agent or
API client pay for a resource inline over HTTP. It was introduced by Coinbase in 2025
(`NOT VERIFIED` — originator and date from model recall).

## Core Idea

When a client requests a paid resource, the server responds `402 Payment Required` with
payment instructions. The client settles the payment (typically an on-chain stablecoin
transfer) and retries the request with a proof-of-payment header; the server verifies and
serves the resource (`NOT VERIFIED` — mechanics from model recall). This turns payment
into a standard, retryable step of an HTTP exchange rather than an out-of-band flow.

x402 matters for the agent economy: autonomous agents need to transact without a human
in the loop, and reviving 402 gives them a payment primitive at the protocol layer.

## Key Properties

- Repurposes the HTTP 402 status code as a live payment challenge.
- Pay-and-retry request flow with a proof-of-payment header (`NOT VERIFIED`).
- Settlement commonly via on-chain stablecoins (`NOT VERIFIED`).
- Enables machine-to-machine / agent-to-API commerce without human intervention.
