Google's engineering teams have contributed foundational open-source projects and specifications
that underpin modern cloud-native infrastructure.

## Key Contributions

- **[SLSA](../concepts/slsa.md)** — Supply-chain Levels for Software Artifacts: supply chain security framework
- **[Sigstore](../concepts/sigstore.md)** — software signing infrastructure (keyless signing via Rekor + Fulcio)
- **SRE model** — Site Reliability Engineering practice, documented in the [SRE Book](../sources/google-sre-book.md)
- **[A2A Protocol](../concepts/agent-to-agent-a2a.md)** — Agent-to-Agent open protocol for multi-agent systems
- **[Universal Commerce Protocol (UCP)](../concepts/universal-commerce-protocol-ucp.md)** — AI commerce protocol
- **Kubernetes** — container orchestration platform (donated to CNCF 2016)
- **Borg** — internal cluster manager that inspired Kubernetes
