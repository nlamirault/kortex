The OpenLineage specification defines a standard for collecting and representing data lineage events.
It includes the Lineage Object Model (LOM) for describing datasets, jobs, and runs.

## Key Components

- **Lineage Object Model**: core data model for lineage events — see [Lineage Object Model](../concepts/lineage-object-model.md)
- **Facets**: extensible metadata attached to lineage events
- **Integrations**: Spark, Airflow, dbt, Flink, and more
