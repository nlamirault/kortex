# x402.org — Internet-Native Payment Protocol

**Author:** x402 Foundation
**Year:** 2026
**Format:** article (project landing page)
**Link:** <https://x402.org/>

## Summary

x402.org presents x402 as "an open, neutral standard for internet-native payments" that
uses the HTTP 402 Payment Required status code to enable direct value transfer between
clients and servers. It targets both humans and AI agents, positioning the absence of a
native HTTP payment layer as the "Internet's original sin" and stablecoin-settled 402
responses as the fix.

## Key Ideas

- **HTTP 402 as the missing rail:** the status code existed but had no protocol; x402
  supplies one, making payment part of the request/response cycle.
- **Agent-first, human-compatible:** removes form-filling, accounts, KYC, and API keys —
  friction that blocks programmatic/agentic usage.
- **Chain-agnostic settlement:** supports "all EVM-compatible chains, Solana, and more,"
  with stablecoins (USDC via ecosystem partners) as the primary vehicle.
- **Zero fees, instant settlement:** no protocol fees; "money moves at the speed of the
  internet."
- **Minimal integration:** a payment middleware wraps existing routes (see quote).
- **Foundation governance:** x402 Foundation launched operationally in 2026 with Alchemy,
  AWS, Cloudflare, Stripe, and Vercel as ecosystem partners.
